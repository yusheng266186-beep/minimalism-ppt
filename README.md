# 极简主义美学 · 互动演示文稿

一份以“哲学、设计与空白之美”为主题的网页演示文稿，用极简视觉语言讲解极简主义的思想来源、设计原则和审美表达。

> 在线演示：[打开互动演示](https://yusheng266186-beep.github.io/minimalism-ppt/)  
> GitHub：[查看源代码](https://github.com/yusheng266186-beep/minimalism-ppt)

## 项目简介

本项目把传统 PPT 的页面结构搬到了浏览器中。画布采用 1280×720 的演示比例，页面在不同屏幕尺寸下自动缩放，适合课堂展示、设计分享、个人作品集或全屏播放。

当前版本包含 10 个幻灯片页面，并配有图片素材、转场动画和演示控制。

## 主要功能

- 10 页主题内容；
- 上一页、下一页按钮；
- 底部圆点导航；
- 全屏演示按钮；
- 当前页淡入、缩放和位移动画；
- 16:9 演示画布自适应手机、平板和桌面屏幕；
- images/ 目录用于存放演示所需图片；
- 极简米白、深蓝和暖棕色视觉系统；
- Inter、Outfit 等字体增强版式层次。

## 内容方向

演示围绕以下问题展开：

- 什么是极简主义；
- 极简主义与“减少”之间的关系；
- 空白、秩序、比例和节奏如何影响设计；
- 极简视觉如何服务于信息表达；
- 极简并不等于单调，而是对内容和形式进行取舍；
- 设计中如何使用颜色、排版、图片和动效建立克制的氛围。

## 使用方式

### 在线演示

打开 Pages 地址后，点击全屏按钮即可开始播放。

### 本地演示

下载仓库后直接打开 index.html 即可。为了确保本地图片路径正常，也可以在仓库目录启动：

    python -m http.server 8080

然后访问：

    http://localhost:8080/

## 操作建议

- 点击下一页按钮前进；
- 点击上一页按钮返回；
- 点击底部圆点跳转到指定页面；
- 使用全屏按钮获得更好的展示效果；
- 在投影仪或大屏幕上播放前，建议先用目标分辨率测试；
- 如果字体无法加载，页面会回退到系统字体，布局仍可使用。

## 目录结构

    minimalism-ppt/
    ├── index.html    # 演示容器、10页内容、样式和交互
    └── images/       # 演示图片资源

## 技术实现

- 原生 HTML、CSS 和 JavaScript；
- CSS Variables 统一管理颜色、字体和画布尺寸；
- CSS transition 和 cubic-bezier 实现页面转场；
- 响应式 transform 处理演示画布缩放；
- GitHub Pages 提供静态托管；
- 外部字体通过 Google Fonts 加载。

项目没有 npm 构建步骤，适合直接部署。若在无网络环境展示，建议提前把字体文件本地化，或接受系统字体回退。

## 修改演示内容

新增或调整页面时：

1. 在 slides-wrapper 中修改对应的 slide；
2. 保持 slide-01、slide-02 这类 id 连续；
3. 如果增加页数，同步更新圆点导航和页码逻辑；
4. 检查文字在 1280×720 画布中是否溢出；
5. 检查移动端缩放和全屏状态；
6. 发布后确认图片相对路径没有变化。
